1. PRODUCT OVERVIEW
Product Name: QNM (Quantized-Concept Network Model)
Form Factor:
  1. Persistent Background Daemon (qnm-daemon)
  2. Fast Terminal CLI Client (qnm)
  3. Drop-In OpenAI-Compatible Local Proxy (/v1/chat/completions)
Primary Goal: Eliminate LLM context-window bloat, reduce KV-cache RAM usage on local machines, and slash token generation latency/cost by sandwiching a reasoning LLM (.gguf or API) between a local NCM Multiscale VQ-VAE Compressor and a local NCM Coarse-to-Fine Parallel Expander.

2. TARGET PERFORMANCE & EFFICIENCY METRICS
- Context Window Compression Ratio: 4x to 8x reduction in stored historical context tokens using NCM coarse hierarchy levels (Level 1 and Level 2).
- Reasoning Output Token Reduction: 70% to 80% reduction in tokens generated by the GGUF/API reasoning model via Concept-Skeleton DSL formatting.
- Local Hardware Target: Runs completely offline inside 6 GB to 8 GB of combined system RAM/VRAM (4-bit quantized 3B-7B .gguf model + FP16/INT8 NCM .pt checkpoints).
- CLI Response Overhead: Less than 15 milliseconds IPC/HTTP overhead between the CLI client and the persistent local daemon.

4. FUNCTIONAL MODULE SPECIFICATIONS

4.1 Module: Literal Symbol Guard (src/qnm/guard/symbol_table.py)
- Responsibility: Protect exact string literals from lossy VQ-VAE quantization.
- Input: Raw user query string and attached file contents.
- Behavior: Detect file paths, URLs, inline code blocks, CLI flags, environment variables, and camelCase/snake_case identifiers. Replace each unique literal with a sequential placeholder token ($SYM_0, $SYM_1, ...) and store the bidirectional mapping for the current request lifecycle.
- Output: Masked text string + Symbol Dictionary.

4.2 Module: NCM Engine Wrapper (src/qnm/ncm_engine/)
- Responsibility: Interface with HazyResearch/ncm PyTorch modules (models/ and tokenization/) and checkpoints from hazyresearch/ncm-checkpoints (specifically xsum for conditional compression and owt for open-ended generation).
- Inbound Compressor (compressor.py): Encodes masked text into multiscale discrete codebook indices across hierarchy levels 1 through K. Truncates fine detail levels above the configured coarse cutoff (default Level 2) and reconstructs a condensed semantic gist.
- Outbound Parallel Expander (expander.py): Accepts the LLM's Concept-Skeleton blueprint as conditioning context. Executes one parallel forward evaluation per hierarchy level from coarse to fine. Supports Classifier-Free Guidance (--cfg 1.0) and Minimum Bayes Risk (MBR) selection across N parallel candidate samples.
- Fallback Requirement: Must include a deterministic algorithmic compression/expansion fallback if .pt weights are not yet present in artifacts/ncm/ or if running on a CPU-only host without CUDA.

4.3 Module: Concept Memory Store (src/qnm/memory/)
- Responsibility: Persist multi-turn conversation history without growing the LLM context window linearly.
- Behavior: Stores each conversation turn's session ID, timestamp, Symbol Dictionary JSON, NCM Level-1 discrete code array, and reconstructed coarse gist in SQLite. Retrieves only the top relevant coarse gists within a strict token ceiling (default 512 tokens) for any new query.

4.4 Module: Local GGUF & API Reasoning Engine (src/qnm/llm_engine/)
- Responsibility: Execute high-level logical reasoning over the NCM-compressed context.
- Local Mode (gguf_provider.py): Loads a local .gguf model file using llama-cpp-python with a restricted context window (default n_ctx = 2048) to conserve RAM/VRAM.
- Concept-Skeleton DSL (skeleton_dsl.py): Enforces a strict output contract on the LLM so it emits structured telegraphic markers ([INTENT], [LOGIC_STEPS], [ENTITIES_AND_SYMBOLS], [RESULT_CORE]) capped at 80 to 120 tokens rather than full paragraphs.

4.5 Module: Persistent Daemon & OpenAI Proxy (src/qnm/daemon/)
- Responsibility: Provide instant, zero-reload access to the QNM pipeline.
- Endpoints:
  1. POST /qnm/query -> Native CLI endpoint returning the final expanded response, raw skeleton, and detailed token-savings telemetry.
  2. POST /v1/chat/completions -> Standard OpenAI-compatible endpoint so external IDEs, coding agents, and SDKs can route traffic through QNM solely by changing their base URL to http://127.0.0.1:8000/v1.
  3. GET /qnm/health & GET /qnm/stats -> Daemon status, loaded model checkpoints, cumulative tokens saved, and memory usage.

4.6 Module: Terminal CLI (src/qnm/cli/main.py)
- Commands Required:
  1. qnm serve -> Boots the persistent background daemon.
  2. qnm download -> Downloads required hazyresearch/ncm-checkpoints and a default 4-bit .gguf model from Hugging Face into artifacts/.
  3. qnm ask "<prompt>" [--file <path>] [--session <id>] [--compression <low|med|high>] -> Sends prompt to daemon, streams or prints the expanded output, and displays a formatted telemetry bar of tokens saved.
  4. qnm stats -> Displays lifetime and session token compression metrics.
  5. qnm clear [--session <id>] -> Wipes stored coarse concept codes for a session.
